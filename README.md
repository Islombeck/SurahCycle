# Murajaah

Murajaah — local-first Flutter-приложение для равномерного повторения выученных сур, фиксации чтений в контексте намаза и пошагового заучивания новых сур. Рабочее название изолировано от доменной модели и может быть заменено позднее.

Основная платформа Sprint 1 — Android. iOS target поддерживается в проекте, но его сборка и подпись выполняются только на macOS.

## Что входит в Sprint 1

- управление выученными сурами, пользовательскими названиями, порядком и активностью в ротации;
- математическая ротация без ручного сброса циклов;
- выбор контекста: Фаджр, Зухр, Аср, Магриб, Иша, Нафль и режим каза для обязательного намаза;
- регистрация прочтения, Undo, история и удаление ошибочной записи с пересчётом;
- базовая статистика по сурам и типам намаза;
- 1–3 объяснимые рекомендации на основе отставания;
- независимый прогресс обучения для каждой выбранной суры;
- полностью локальная работа основной функциональности;
- Material 3, русский интерфейс и тёмная тема;
- проверенный offline-каталог метаданных 114 сур и независимая архитектура поставщиков Quran content;
- явное состояние «текст аятов и переводы не загружены» без подстановки выдуманных данных.

В приложение включён только официальный metadata-файл Tanzil.info v1.0 (названия и количество аятов, CC BY), проверяемый структурно при запуске. Арабский текст аятов и переводы намеренно не включены. Проект не содержит придуманных Quran-данных. Подробнее: [источники данных](docs/QURAN_DATA_SOURCES.md).

## Требования к окружению

Целевая среда проекта:

- Flutter `3.44.7` stable (Dart входит в Flutter SDK);
- Java/JDK `17` для Android toolchain;
- Android SDK и platform-tools;
- для iOS — macOS, Xcode и при необходимости CocoaPods.

Проверьте окружение:

```powershell
flutter --version
dart --version
java -version
adb version
flutter doctor -v
flutter devices
```

Если Flutter хранится локально в `.tools/flutter` и не добавлен в `PATH`, на Windows замените `flutter` в командах на:

```powershell
.\.tools\flutter\bin\flutter.bat
```

## Основные правила данных

- пользовательские события сначала атомарно сохраняются локально;
- сеть не участвует в регистрации прочтения;
- `totalRecitations` выводится из сохранённых событий, а не редактируется вручную;
- ручной перенос текущего баланса записывается отдельной корректировкой `rotationScore`;
- удаление события перестраивает производные данные;
- Quran content и пользовательская история хранятся раздельно, поэтому обновление контента не удаляет прогресс.

## Статус внешних систем

Sprint 1 не требует backend, аккаунта, синхронизации, геолокации или внешнего Quran API. Каталог сур доступен из bundled asset без сети. Отсутствие сети либо недоступность поставщика полного Quran content не блокируют ротацию, историю, статистику и обучение; интерфейс честно сообщает, что текст аятов и переводы пока не загружены.
